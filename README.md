Internet Speed Logger

A simple Python project that tests your internet connection and saves the results in a CSV file.

Features

Measures download and upload speeds in Mbps
Checks ping in milliseconds
Saves results with date and time
Supports multiple tests at different intervals

Installation

First step you need to install the required library:
pip install speedtest-cli
Usage

Run the program:
python speed_logger.py

Results are saved automatically in speed_log.csv, which can be opened in Excel.

Technologies that i used:

speedtest-cli
